## 它能帮你做什么

人生存档是一款在自己设备上运行的信息整理与重要事项交接工具。可以用它记录重要账号、资产线索、文件放在哪里、宠物安排、联系人，以及希望别人如何帮你处理事情。

它适合日常整理、备份迁移和提前留下交接线索。不需要一次填写完整，也不要求你拥有某类账号、资产或宠物。

- 四个章节：我的数字世界、我的现实世界、我在乎的人和事、如果有一天。
- 主动保存到当前电脑的当前浏览器；也可生成加密或未加密的 `.life` 备份。
- 导入备份，恢复内容；支持完整人生存档、执行人指南、人生存档卡三种打印。
- 可选的 5 分钟快速开始、用户须知、安全与使用说明，以及非强制的整理状态提示。
- 可填写存档人称呼，也可以留空。
- 先添加联系人，再从联系人中设置执行人。执行人可以多位，第一联系人和备用联系人分别最多一位。前三个章节的事项卡片可以选择一位负责执行人，也可以暂不指定。

| 章节 | 可以整理的内容 |
| --- | --- |
| 我的数字世界 | 社交账号、邮箱与云盘、游戏账号、数字资产、数字作品、设备和订阅 |
| 我的现实世界 | 金融资料、证件、合同、房产车辆、重要物品和文件位置 |
| 我在乎的人和事 | 宠物、植物、纪念品、赠予意愿、照片作品和特殊安排 |
| 如果有一天 | 联系人、执行人安排、账号处理、隐私清理、宠物最终安排、留言和存档获取线索 |

## 保存和备份有什么区别

**保存人生存档**：把当前内容保存在当前电脑的当前浏览器里，下次打开可以继续使用。新增、编辑或清空后的变化都需要主动保存；没有保存就离开，会丢失这次修改。关闭或刷新时浏览器会按自身规则显示未保存提醒，请不要只依赖提醒。

**保存并备份**：选择备份方式并最终确认完成时，保存当前内容，并额外生成一个可以带走的 `.life` 文件。仅打开备份窗口后取消，不会保存这次修改。

- 加密备份：需要设置密码。以后恢复时需要该密码，软件无法找回忘记的密码。
- 未加密备份：不需要密码，但拿到文件的人可能查看其中内容，生成前需确认隐私提醒。

本机保存不是加密保险箱，也不等于做好备份。清理浏览器数据、换浏览器或更换软件位置后，原来的本机内容可能不可用。请另外保管好 `.life` 副本；不要以复制软件文件夹代替备份个人内容。

## 如何恢复 .life 文件

不要把双击 `.life` 当作恢复方法。请按以下顺序操作：

1. 打开人生存档，点击“导入/恢复人生存档”。
2. 选择 `.life` 文件；如果设置过密码，输入当时的密码。
3. 检查恢复的内容，再点击“保存人生存档”。

导入先打开到当前页面中，不会自动覆盖此前本机保存的版本。导入前请先保存或备份当前需要保留的修改。换电脑时也按以上步骤恢复。

换电脑迁移：旧电脑“保存并备份” → 安全携带 `.life` → 新电脑解压软件 → 导入备份 → 核对内容 → “保存人生存档”。单独复制软件不会带走旧浏览器里的数据。

## 如何打印

点击“导出打印”，选择完整人生存档、执行人指南或人生存档卡，阅读并确认明文副本提醒后继续。

- 完整人生存档：供自己保存和核对，仍遵守每张卡片的打印范围。
- 执行人指南：供协助处理事情的人查看，按所选范围输出事项信息。
- 人生存档卡：精简的交接线索，帮助可信的人知道存档在哪里、应找谁。

每张卡片里的“打印范围”只决定它在对应打印文件中是否出现、显示多少，不影响该卡片在软件中的保存。人生存档卡默认不显示；可以主动选择摘要或显示安全字段，并非直接输出所有原始字段。填写时的“负责执行人（可选）”有值时会打印为“负责执行人”。

**保存 PDF 前请先检查打印预览。若出现本地文件路径、日期等附加信息，请关闭“页眉和页脚”；如果当前打印方式没有该选项，可尝试切换为“Microsoft Print to PDF”。** 软件不会自动关闭浏览器的页眉页脚。

## 本地离线和隐私

程序不需要服务器、账号或注册，不自动上传填写内容，不自动通知联系人，也不会判断你是否发生意外。你主动使用邮件客户端或访问文档中的外部链接，会使用相应外部服务；这不等于软件替你上传存档。

不要填写真实账号密码、支付密码、验证码、私钥或助记词。可以记录“密码放在哪里”“验证设备在哪里”等线索。

软件通过字段白名单、关键词和格式规则限制部分敏感信息输出，但**不能保证识别所有形式的密码、密钥或其他秘密**。用户仍须自行检查准备保存、备份或打印的内容；安全提醒不代表完整安全检测。未加密备份、打印文件以及本机保存内容都可能包含个人隐私。

整理好 → 保存好 → 备份好 → 至少让一个可信的人知道存档存在以及去哪里找。

本工具用于整理信息和记录意愿，不替代正式法律安排，也不保证平台账号能够继承、转让或恢复。
