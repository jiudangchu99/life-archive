# 数字账号与资产整理建议

这里帮助你留下“有什么、在哪里、以后由谁按什么线索处理”的说明，不要求你拥有特定资产，也不是投资或账号转让教程。

## 账号应该记录什么

记录平台名称、账号识别线索、用途、重要内容位置、密码保存位置、验证设备位置和处理建议。按需要选择负责执行人，也可以暂不指定。

不要记录真实密码：本机内容、打印稿和未加密备份可能被他人取得。可以写“密码保存在密码管理器里”“密码提示在家中密封信封”“验证设备是备用手机”，不要写密码、验证码或恢复密钥本身。

| 内容 | 建议留下的线索 |
| --- | --- |
| 社交账号 | 平台、识别方式、希望保留或清理的内容、官方处理渠道 |
| 邮箱与云盘 | 主要用途、重要文件夹、恢复线索和备份位置 |
| 游戏账号 | 平台、账号标识、物品说明、处理意愿；先核对平台规则 |
| 照片和视频 | 原文件在哪里、哪些特别重要、独立副本在哪里、希望交给谁 |
| 数字作品 | 作品名称、源文件位置、权属说明、保留或交接意愿 |
| 设备与订阅 | 设备位置、重要数据位置、续费和取消方式线索 |

重要照片和文件建议保留多个独立副本，定期确认能打开。人生存档记录位置和线索，不自动备份这些照片或文件本身。

## 金融账户与数字资产

金融资料可以记录机构、账户用途、适当的识别提示、合同或凭证位置、机构联系线索和处理方式。不要填写支付密码、验证码或完整验证凭据。机构服务人员与负责执行人不是同一个概念。

交易平台资产、链上钱包、NFT 等可在“我的数字世界”的“数字资产”卡片中选择相应类别，记录平台、钱包或项目名称、必要说明、资料或设备位置、负责执行人（如需）和恢复线索位置。

不要记录真实私钥、助记词、密码或交易签名材料，也不要通过反馈邮件发送它们。交接前安排可信的人如何安全取得必要资料；这里不提供交易操作或绕过平台验证的方法。

账号使用权、游戏物品和数字资产能否转让、继承或恢复，取决于平台规则及具体情况。人生存档只记录线索和意愿，不保证平台执行安排，也不自动转移资产。

## 可以提前了解的官方工具

以下简述于 **2026-11-02** 核对官方资料，只是阅读入口，不承诺适用于所有账户、地区和设备。平台政策可能变化，请以最新官方规则为准。

- Apple 提供遗产联系人设置，可在符合条件时申请访问部分账户数据；并非所有购买内容或密码都能取得。见 [Apple 官方说明](https://support.apple.com/en-my/102631)。
- Google 的闲置账号管理工具可按设置的条件通知指定的人或分享部分数据。此功能属于 Google，需要单独设置，人生存档不会替你启用。见 [Google 官方说明](https://support.google.com/accounts/answer/3036546)。
- Steam 的账号及订阅使用受协议约束，不应假定可自由出售、转让或把密码交给别人。见 [Steam 订户协议](https://store.steampowered.com/agreement/?l=english) 的账户和授权条款。

这些网页需你主动联网访问，软件不会后台连接平台。本指南使用简短原创说明指向官方页面，不包含第三方截图、图标、字体或大段转载。

## 让线索真正有用

先添加联系人，再从中设置一位或多位执行人，给需要的事项选择负责执行人。提前让可信的人知道存档在哪里、加密备份的密码线索在哪里，不要只留下一个无人知道或无人能打开的文件。
