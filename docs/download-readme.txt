人生存档 · Life Archive V1.0
符合许可证条件的非商业使用免费

1. 完整解压文件夹，然后双击 index.html。建议使用 Edge 或 Chrome。
2. 不要只移动 index.html；app.js 和 styles.css 必须和它放在一起。
3. 不需要安装 Node.js、Python 或 Playwright，不需要注册或服务器。
4. 5分钟快速开始完全可选，不用全部填写。
5. 保存卡片后，再点击“保存人生存档”，才会保存到当前电脑的当前浏览器。
6. “保存并备份”在你最终确认后保存当前内容，并生成 .life 文件。取消备份窗口不会保存修改。
7. 恢复时：打开人生存档 → 导入/恢复人生存档 → 选择 .life → 如有密码则输入 → 核对内容 → 保存人生存档。不要直接双击 .life 恢复。
8. 本机保存不是加密保险箱。重要资料应另做备份，换电脑时用 .life 迁移。加密备份密码忘记后无法找回。
9. 打印范围只决定打印时出现哪些资料、显示多少，不影响软件里保存的数据。PDF 和未加密 .life 都可能包含个人隐私。
10. 保存 PDF 前检查预览；出现本地路径、日期等附加信息时关闭“页眉和页脚”。没有此选项时可以尝试 Microsoft Print to PDF。软件不能自动关闭它。
11. 不要填写真实密码、支付密码、验证码、私钥或助记词。软件不能保证检测所有敏感内容。
12. 软件不会自动判断意外，也不会自动通知联系人。请提前让至少一个可信的人知道存档存在、放在哪里、去哪里找解锁线索。

整理好 → 保存好 → 备份好 → 让可信的人知道怎么找到。
