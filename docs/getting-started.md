# 第一次使用人生存档 · Life Archive

## 打开和开始

完整解压下载包，再双击 `index.html`，建议使用较新的 Edge 或 Chrome。三个程序文件请放在一起，不要只移动 HTML。普通用户不用安装 Node.js、Python 或 Playwright。

首次在没有保存记录的浏览器中打开，会看到用户须知和空白存档。同一浏览器可能恢复你以前保存的内容，这不代表下载包里附带了资料。

5 分钟快速开始完全可选，可以不使用、只填一项、全部跳过或直接关闭。首页四个“+”分别打开联系人、数字世界账号、贵重物品、特殊安排的新增界面。没有填写就关闭不会新增空卡片。

从重要联系人、账号、文件位置或需要照顾的事情开始。没有的内容不用填，以后可以补充。“检查我的存档”是状态提醒，不是必须全部打勾的任务。首页存档人称呼可以填写姓名、昵称或其他称呼，也可以留空；填写后随保存、备份和打印保留。

## 联系人和执行人

先在“如果有一天”添加联系人，再从已有联系人中设置执行人。联系人可以多位，第一联系人和备用联系人分别最多一位，执行人可以多位，一个人可以兼任不同身份。

前三个章节的事项卡片可以选择一位“负责执行人”，也可以暂不指定。普通联系人不会自动成为执行人。机构服务人员、合同对接人等事项本身的联系线索，和负责执行人是不同概念。

## 填完记得保存

“保存卡片”只是把卡片加入当前页面。要让下次打开还能看到，请再点击“保存人生存档”。以后修改了内容，也要重新保存。

- **保存人生存档**：保存到当前电脑的当前浏览器，不要求密码，不生成 `.life`。
- **保存并备份**：选择备份方式并最终确认下载时，保存当前内容并生成 `.life`。仅打开选择窗口后关闭，不会保存修改。

没有保存就刷新或关闭，这次修改不会保留；以前保存过的版本仍是上一次保存的内容。浏览器可能提示未保存，但不要只依赖弹窗。清空人生存档也要另行保存才会替换本机版本，已经下载的备份不会因此删除。

## 再做一份能带走的备份

`.life` 是恢复、迁移和交接用的文件，不是直接双击阅读的文档。

- 加密备份：设置并确认密码，恢复时需要输入。忘记密码后无法找回，请提前安排密码或解锁线索的获取方式。
- 未加密备份：无需密码，生成前需确认风险。任何取得文件的人都可能看到其中的信息。

请把备份放在信任的位置，重要内容保留独立副本。不要把真实密码写进人生存档，可以写“密码在保险柜的密封信封里”。备份和密码获取安排都应妥善保管。

## 恢复与换电脑

1. 打开人生存档，点击“导入/恢复人生存档”。
2. 选择之前的 `.life`；如为加密备份，输入当时的密码。
3. 检查恢复内容是否正确。
4. 点击“保存人生存档”，让它成为当前电脑的本机版本。

导入只是打开到当前页面，不自动覆盖此前本机保存的版本；导入前先保存或备份当前要保留的修改。换电脑前在旧电脑“保存并备份”，把软件和 `.life` 分别带到新电脑，再按上述步骤恢复。仅复制程序文件夹不会迁移浏览器里保存的内容。

## 打印范围是什么意思

打印范围只决定这张卡片出现在什么打印文件里、显示多少，不影响资料在软件中保存。

| 打印内容 | 用途 |
| --- | --- |
| 完整人生存档 | 给自己核对和长期保管；仍遵守卡片的详细显示、摘要或不显示选择 |
| 执行人指南 | 给以后协助处理事情的人，按选择提供事项细节或摘要 |
| 人生存档卡 | 简要交接提示，可记录存档获取线索和应该找谁 |

人生存档卡默认不显示卡片，可主动选择摘要或显示安全字段。“安全字段”不等于全部原始字段，也不保证没有敏感内容，请检查预览。例如游戏账号可以在完整版显示细节，在执行人指南显示摘要，在人生存档卡不显示。

在“如果有一天”的“正式存档获取线索”中，可以记录 `.life` 放在哪里、密码提示去哪里找，不要填写密码本身。

点击“导出打印”，选择输出并确认明文风险后继续。**保存 PDF 前，请先检查打印预览。若出现本地文件路径、日期、网页标题或页码等浏览器附加信息，请在打印设置中关闭“页眉和页脚”。如果当前“另存为 PDF”没有该选项，可以尝试选择“Microsoft Print to PDF”等其他打印方式。不同浏览器版本和设备显示的选项可能略有不同。** 软件无法自动替你关闭该设置。

## 最重要的交接安排

整理好 → 保存好 → 备份好 → 至少让一个可信的人知道存档存在以及去哪里找。

软件不会自动知道你是否发生意外，也不会自动通知联系人。可以提前告诉可信的人“我留了一份人生存档，大概放在哪里，遇到事情应该找谁”。不必现在就把全部资料交给对方。

不要填写真实账号密码、支付密码、验证码、私钥或助记词。本机保存不是加密保险箱，PDF 和未加密 `.life` 可能包含隐私。另见 [隐私与安全](privacy-and-safety.md)。
